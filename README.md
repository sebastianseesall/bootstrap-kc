# Bootstrap Registration Project

A responsive web application built with Bootstrap 5.3.3 featuring user registration, data display, and modern web design principles.

## Features

- **Responsive Design**: Mobile-first approach with Bootstrap's grid system
- **Interactive Navigation**: Collapsible navbar that adapts to screen size
- **Registration Form**: Complete form with validation and Bootstrap styling
- **Data Display**: Responsive table showing user submissions
- **Semantic HTML**: Proper use of semantic tags for accessibility
- **Modern Styling**: Clean, professional appearance using Bootstrap components

## Getting Started

### Prerequisites

- A modern web browser
- Internet connection (for Bootstrap CDN)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/sebastianseesall/bootstrap-kc.git
   ```

2. Navigate to the project directory:
   ```bash
   cd bootstrap-kc
   ```

3. Open `index.html` in your web browser or serve it using a local server:
   ```bash
   # Using Python
   python3 -m http.server 8000
   
   # Using Node.js
   npx serve .
   ```

4. Open your browser and navigate to `http://localhost:8000`
